# My Portfolio (Next.js Laboratory Project)

This is a personal portfolio website built using **Next.js (App Router)**, **TypeScript**, and **Tailwind CSS** as part of a laboratory exercise. The project demonstrates reusable components, proper folder structure, and modern frontend development practices.

## Learning Objectives

By completing this project, I learned how to:

- Understand Next.js project structure and file-based routing
- Create reusable React components
- Apply component composition and prop drilling
- Use TypeScript for type-safe development
- Organize scalable folder structures
- Work with client and server components
- Deploy a Next.js app using Vercel

## 🛠 Tech Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- React
